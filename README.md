# BrightLearn-SQL-fundamentals-Exercises

## About This Repository

This is my BrightLearn SQL Fundamentals and Aggregate & Operators exercise work. I am a student learning data analytics with the goal of landing a job in the field. These pen-and-paper exercises are part of my journey to build a strong SQL foundation — one of the core skills required in data analytics roles. This repository documents my answers, the challenges I faced, and what I took away from each exercise.

**Course:** BrightLearn Basic SQL
**Exercises Completed:** Exercise 01 · SQL Fundamentals & Exercise 02 · SQL Aggregates & Operators

## What These Exercises Covered

Exercise 01 focused on the fundamentals — using `SELECT`, filtering rows with `WHERE`, sorting with `ORDER BY`, and removing duplicates with `DISTINCT`.

Exercise 02 built on that foundation by introducing aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`), grouping data with `GROUP BY`, filtering groups with `HAVING`, and aliasing columns with `AS`.

## Challenges

The most challenging part of these exercises was working with `GROUP BY` and `HAVING` together. Knowing when to use `HAVING` versus `WHERE` required a shift in thinking — `WHERE` filters individual rows before grouping happens, while `HAVING` filters the groups after. I understand the distinction now, but it will take more repetition before it feels completely natural.

---

## What I Learned

The biggest takeaway from both exercises was understanding how aggregate functions summarise data. Functions like `SUM()`, `AVG()`, and `COUNT()` collapse multiple rows into a single meaningful result, which is a powerful shift from just reading raw rows. Combining that with `GROUP BY` to break results down by category made the output much more useful and realistic.

---

## Confidence Check

My basics feel solid. I can write `SELECT` queries, apply filters, sort and limit results, and use aggregate functions with grouping. The next step is practice — particularly around `GROUP BY` and `HAVING` — to move from understanding to instinct.
